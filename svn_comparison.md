1. В Git ветка — ссылка на коммит, поэтому ее создание локально и быстро.
   В SVN ветка обычно представлена каталогом репозитория и создается
   серверной операцией copy. SVN использует cheap copies, поэтому
   создание ветки не копирует физически все содержимое и тоже может
   быть дешевым. Отличия заметны в рабочем процессе и зависимости от сервера.
2. Без доступа к серверу SVN создать обычный коммит нельзя:
   новая ревизия фиксируется в центральном репозитории.
   Интернет не требуется, если сервер доступен в локальной сети.
   Git позволяет создавать коммиты локально без сетевого подключения.
3. SVN может быть удобен в существующей централизованной инфраструктуре,
   при необходимости ограничивать доступ по каталогам и использовать
   блокировки для двоичных файлов, которые трудно объединять.
